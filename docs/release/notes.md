# Her World 0.4.0

这一版统一了生活世界的照料动作、计划命令和事实记录。设置页按伙伴支持的动作显示照料按钮，已有计划、账本和历史记录可以继续使用。

## 从 0.3.0 升级

已在 0.3.0 正常使用的安装，可在 DSH 的 **Her World → 版本** 直接更新。**从 0.3.0 升级无需离线迁移。**

仍在 0.2.0 的安装，先按 [从 0.2.0 升级到 0.3.0](https://github.com/hyyino7/her-world/blob/v0.3.0/docs/development.md#upgrade-0-3-0) 完成旧版迁移。

## 预发布验收

先在隔离环境的版本页勾选「预发布」并更新。逐个点设置页的照料按钮，在桌宠各选一次吃饭和睡觉素材，再在聊天里确认伙伴记得刚才的照料。
